# Council Decisions Dashboard (demo)

Arabic/RTL dashboard for tracking council decisions and the meetings they came from.
Work in progress, shared for review.

**Live:** https://ashahrourr.github.io/psmr-council-decisions/

This repo holds only the built single-file app. Source lives in the team repo under
`projects/psmr/adhocs/executive-office-management/`. All data shown is fictional demo data,
and it is stored in each visitor's own browser (localStorage), never on a server.
